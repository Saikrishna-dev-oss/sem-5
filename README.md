## Contents Overview

### AI
Contains Python programs and practice files related to:
- Factorial
- Fibonacci
- Prime checking
- Multiplication table
- List operations
- Water jug problem
- BFS and DFS
- Best-first search
- CSP
- Alpha-beta pruning

### CN
Contains Java programs for:
- Bit stuffing
- Byte stuffing
- Stop-and-Wait protocol
- Go-Back-N protocol
- Cyclic Redundancy Check (CRC)

### SML
Contains R scripts for:
- Probability and distributions
- Descriptive statistics
- Uniform and normal distributions
- Hypothesis testing
- t-tests and F-tests
- Chi-square analysis
