WEEK 8 — EXPERIMENT 2: DISTANCE VECTOR ROUTING (RIP)
============================================================

Packet Tracer file: DistanceVector.pkt

AIM
---
Configure and verify Distance Vector Routing using RIP between three routers.

DEVICES IN THIS FILE
--------------------
- 3 Cisco 1841 routers: Router0, Router1, Router2
- 3 Cisco 2960-24TT switches: Switch0, Switch1, Switch2
- 6 PCs: PC0 to PC5

IMPORTANT
---------
This saved file uses Cisco 1841 routers:
- LAN interface: FastEthernet0/0
- WAN interfaces: Serial0/0/0 and Serial0/0/1

Use these interface names. Do not use GigabitEthernet interfaces from the
manual's different example.

STEP 1 — OPEN THE PACKET TRACER FILE
------------------------------------
1. Open Cisco Packet Tracer.
2. Open DistanceVector.pkt.
3. Check that all 3 routers, 3 switches and 6 PCs are present.
4. Check that the router-to-router serial links and PC/switch/router links
   are connected.

STEP 2 — CHECK THE PC IP CONFIGURATION
--------------------------------------
For each PC:
1. Click the PC.
2. Select Desktop.
3. Open IP Configuration.
4. Check the IP address, subnet mask and default gateway.

PC0: IP 192.168.1.2 | Mask 255.255.255.0 | Gateway 192.168.1.1
PC1: IP 192.168.1.3 | Mask 255.255.255.0 | Gateway 192.168.1.1

PC2: IP 192.168.2.2 | Mask 255.255.255.0 | Gateway 192.168.2.1
PC3: IP 192.168.2.3 | Mask 255.255.255.0 | Gateway 192.168.2.1

PC4: IP 192.168.3.2 | Mask 255.255.255.0 | Gateway 192.168.3.1
PC5: IP 192.168.3.3 | Mask 255.255.255.0 | Gateway 192.168.3.1

STEP 3 — CHECK ROUTER INTERFACE CONFIGURATION
---------------------------------------------
Click each router, open CLI and press Enter.

On Router0, enter:
  enable
  show ip interface brief

Check these interface addresses:
  FastEthernet0/0 = 192.168.1.1
  Serial0/0/0     = 10.0.0.1
  Serial0/0/1     = 12.0.0.1

On Router1, enter:
  enable
  show ip interface brief

Check:
  FastEthernet0/0 = 192.168.2.1
  Serial0/0/0     = 10.0.0.2
  Serial0/0/1     = 11.0.0.1

On Router2, enter:
  enable
  show ip interface brief

Check:
  FastEthernet0/0 = 192.168.3.1
  Serial0/0/0     = 11.0.0.2
  Serial0/0/1     = 12.0.0.2

The interfaces should show an up/up status after the links are active.

STEP 4 — CHECK SERIAL DCE CLOCK RATE
------------------------------------
The saved file uses a clock rate of 2000000 on these DCE interfaces:

- Router1: Serial0/0/0
- Router2: Serial0/0/0
- Router2: Serial0/0/1

To check the DCE end of a serial cable:
1. Click the serial connection in Packet Tracer.
2. Identify which router interface is marked DCE.
3. On the listed DCE interfaces, the saved configuration uses:

  clock rate 2000000

Do not configure clock rate on the DTE end.

STEP 5 — CHECK RIP CONFIGURATION
--------------------------------
The saved configuration uses these RIP network statements:

  network 10.0.0.0
  network 11.0.0.0
  network 12.0.0.0
  network 192.168.1.0
  network 192.168.2.0
  network 192.168.3.0

On EACH router:
1. Open CLI.
2. Enter:

  enable
  show running-config

3. Find the router rip section.
4. Check that the network statements above are present.

If you need to enter the saved RIP network statements manually, use:

  configure terminal
  router rip
  network 10.0.0.0
  network 11.0.0.0
  network 12.0.0.0
  network 192.168.1.0
  network 192.168.2.0
  network 192.168.3.0
  end

Repeat on Router0, Router1 and Router2.

NOTE:
The supplied saved configuration does not show 'version 2' or
'no auto-summary'. The instructions above preserve the RIP statements
found in the saved file; they do not add those commands from the PDF example.

STEP 6 — VERIFY ROUTING TABLES
------------------------------
On each router, enter:

  enable
  show ip route

Check that routes to the other routers' LAN networks are learned through RIP.
RIP-learned routes are marked with the letter R.

STEP 7 — TEST END-TO-END CONNECTIVITY
-------------------------------------
1. Click PC0.
2. Open Desktop.
3. Open Command Prompt.
4. Enter:

  ping 192.168.3.3

5. Check whether PC0 receives replies from PC5.
6. If the first ping times out, wait briefly and run the same command again.

EXPECTED RESULT
---------------
PC0 should successfully receive ping replies from PC5 (192.168.3.3) after
the routers have exchanged routing information and the network has converged.

STEP 8 — SAVE THE FILE
----------------------
1. Press Ctrl + S.
2. Keep the filename:

  DistanceVector.pkt

QUICK COMMAND SUMMARY
--------------------
Router checks:
  enable
  show ip interface brief
  show running-config
  show ip route

PC connectivity test:
  ping 192.168.3.3

IMPORTANT TROUBLESHOOTING
-------------------------
- If a router interface is down, check the cable and interface status.
- If a serial link is down, check the DCE clock rate on the DCE interface.
- If a RIP route is missing, check the RIP network statements on that router.
- If the first ping fails, retry after routing information has converged.
- Make sure each PC's default gateway matches its connected router's
  FastEthernet0/0 address.
